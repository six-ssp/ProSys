# Local-Only Archive

This directory is intentionally ignored by Git except for this index. It holds
retired local experiments and helper scripts that should not appear in the
repository root or be reported as mainline evidence.

Current categories:

- `joint_negative/`: stopped joint Stage-2/Stage-3 and wrong-route-negative
  experiments.
- `serial_stage2_pilots/`: superseded serial Stage 2 pilot outputs.
- `stage3_probes/`: local capacity/probe notes not promoted to a result record.
- `retired_scripts/`: scripts coupled to the stopped joint/negative experiments.

Files here are preserved locally for recovery. They are neither maintained
code nor GitHub deliverables.
